# Projet Individuel Innovant : Smart Home

## Contexte

Ce projet fait partie du **Projet Individuel Innovant (PII)**, supervisé par **Madame Grislin**, et réalisé dans le cadre de mes études à l'**INSA Hauts-de-France**.

## Objectif

Le but de ce projet est de proposer une expérience innovante autour du concept de **Smart Home**. Le projet sera traduit pour être utilisable par le **cube VR** qui est mis à disposition par l'INSA Hauts-de-France. Le projet s'articule autour des fonctionnalités suivantes :

1. **Création et personnalisation d'un appartement :**
   - L'utilisateur peut concevoir un appartement.
   - Une bibliothèque d'éléments permet de construire et de personnaliser l'espace (meubles, décoration, etc.).

2. **Visualisation en vue 3D :**
   - L'utilisateur peut visualiser l'appartement et voir le rendu final dans un espace 3D immersif.

3. **Exploration et interaction :**
   - L'utilisateur peut explorer son appartement en **vue à la troisième personne**.
   - Le projet prévoit l'intégration de fonctionnalités interactives pour simuler un **appartement connecté** (contrôle de lumières, appareils intelligents, etc.).

4. **Import /Export**
   - il est possible de créer plusieurs appartements sous forme de sauvegarde, de les exporter, de les importer et de les charger.

## Technologies utilisées

- **Unity** : Utilisé pour le développement du projet.
- **C#** : Langage de programmation pour les scripts et la logique du jeu.
- **Blender** : Utilisé pour la modélisation des objets 3D.

## Fonctionnalités principales

- **Mode Éditeur :**
  - Drag-and-drop d'éléments pour construire l'appartement.
  - Barre d'outils disponible avec les éléments préconfigurés.

- **Mode Jeu :**
  - Exploration de l'appartement avec des contrôles de joueur.
